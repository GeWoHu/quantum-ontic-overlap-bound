# Reproduction guide

Everything here is exact rational arithmetic. No floats, no sampling, no
optimization, no trust in any log shipped with this repository.

## Requirements

- Python ≥ 3.10 with `sympy ≥ 1.12` (tested with sympy 1.14.0)
- `tectonic` (or any LaTeX distribution with amsmath/amsthm) to rebuild the PDF
- ~10 minutes CPU for the full certificate re-verification

## Step 1 — Verify all 68 certificates + reconstruct the ledger (the single computational step)

```bash
cd certificates
python3 verify_certificates.py
```

Expected final line:

```
VERIFY DONE: 70 entries reconstructed-and-confirmed, 0 mismatches, 2 corner models verified by explicit substitution (70 ledger entries)
```

What it does: for each entry of `CERT_LEDGER.json` it independently re-derives the true symbolic zero-set support, the model generators, and the Groebner basis from the entry's cell and pattern alone, cross-checks every stored field, enforces the exact expected id set and count, and verifies the two corner models by explicit substitution. For each of the 68 excluded strata it
recomputes the reduced lexicographic Gröbner basis over ℚ of the ideal
generated by the published polynomial generators together with (1 − y),
with response variables and (p, q) eliminated before y, and checks the
basis contains a nonzero constant — i.e. 1 lies in the ideal, so by
Hilbert's Nullstellensatz the stratum has no complex solution, a fortiori
no stochastic model. The 2 skipped strata are the feasible corner models
(0,1) and (1,0), verified by explicit substitution instead (Appendix B of
the manuscript).

## Step 2 — Regenerate the ledger from the model (optional, ~10 min)

```bash
cd certificates
python3 export_certificates.py
# expected final line: === EXPORT DONE: 70 strata, 68 certified 1-in-ideal
diff <(python3 -c "import json;print(len(json.load(open('CERT_LEDGER.json'))))") \
     <(echo 70)
```

## Step 3 — Independent reconstruction (Case A, equality cases, break search)

```bash
cd verification
python3 verify_independent.py
```

Expected: exactly 2 feasible Case-A models σ=(1,0,3,2) at (p,q)=(1/4,3/4)
and σ=(2,3,0,1) at (3/4,1/4), both with ω²/Σδ = 1/2 exactly; corner models
verified; spot-certificates 1 ∈ I. (This is an independent code path with a
different variable layout from `certificates/`.)

## Step 4 — Check the hashes

```bash
sha256sum -c MANIFEST.sha256
```

All published files must report OK.

## Step 5 — Rebuild the PDF

```bash
cd manuscript
tectonic main.tex        # or: pdflatex main.tex
```

## Trust model

The mathematical skeleton (Lemmas 1–3, double-zero locus, Case-A
determinism derivation, mixed-side inequality) is hand-checkable from the
PDF. The only computer-assisted step is Step 1; its inputs are the
generator lists in `CERT_LEDGER.json`, which are readable polynomial
identities derived directly from the model definition in Section 2 of the
manuscript. Residual trust: sympy's Gröbner implementation (cross-check
with Macaulay2/Singular welcomed — see REVIEW_REQUEST.md Front 2).
